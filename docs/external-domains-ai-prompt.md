# 用 AI 整理 SniRoute 外置域名清单

复制下面的提示词，并在末尾粘贴你自己的原始材料。将 AI 返回的 JSON 保存为 UTF-8 文件，核对后放到可直接下载的 HTTPS 地址。

```text
请把末尾的原始材料整理为 SniRoute 外置域名清单。

只输出一个合法 JSON 对象，不要 Markdown 代码围栏、注释、解释或省略号。
结构必须为：
{
  "version": "v1",
  "name": "我的自定义清单",
  "domains": [
    {"domain": "chat.example", "category": "AI 服务"},
    {"domain": "assets.example", "category": "其他"}
  ]
}

规则：
1. 只使用原始材料实际出现的域名，不补猜域名，不声称已经验证网络可达性。
2. 来源若为完整 URL，只提取 hostname；输出中不能带协议、端口、路径、查询串或片段。
3. 域名统一小写、去掉末尾的点、按域名去重，第一次有效出现的条目优先。
4. 域名至少两段，总长度不超过 253 个 ASCII 字符，每段 1–63 字符，只能含英文字母、数字和连字符，每段首尾不能是连字符；最后一段必须含字母。
5. 排除 IP、非法 IP、通配符、下划线、空值和无法可靠识别的字符串；不要猜测修复。国际化域名只在能准确转换为 Punycode 时保留，否则跳过。
6. 按材料中已有的分类整理；未指定、无法确定的分类统一写“其他”，不要凭域名猜测服务商、ASN 或可达性。
7. category 为最多 64 个字符的单个字符串，不用数组或 null；分类名称不含换行、制表符等控制字符，最多 64 个不同分类。
8. name 可省略，若填写则为最多 80 个字符的字符串。除 version、name、domains 及条目内 domain、category 外，不添加其他字段。
9. 文件必须使用 UTF-8，最多 2 MiB，domains 最多 10000 项。若无有效域名，输出 {"version":"v1","name":"无有效域名","domains":[]}，不要编造条目；这个空清单不能直接导入，需要先补充有效材料。
10. 不要把外置清单链接当作待测域名；不要生成可执行脚本或配置探测 IP、代理、TLS、基线等参数。

原始材料：
（在这里粘贴域名、网站链接和已有分类）
```
