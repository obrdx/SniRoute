# 自定义域名清单

[返回首页](../README.md) · [使用指南](usage.md)

## 选择与合并清单

进入客户端菜单 **2「选择要测试的域名」**：

| 编号 | 清单 | 后续操作 |
| --- | --- | --- |
| 1 | 默认清单（快速，231 个域名） | 使用内置快速清单 |
| 2 | 完整清单（1100 个域名） | 使用内置完整清单 |
| 3 | 按内置分类选择 | 进入分类界面，再输入分类编号，可多选 |
| 4 | 自定义外置清单（JSON） | 进入链接界面，输入 HTTPS 文件原始内容链接 |

支持空格、逗号或 `+` 组合编号。例如输入 **`1 4`**，然后在下一个界面输入外置链接，即合并默认清单与自定义清单，按域名去重。输入 `4` 则只使用外置清单，基线仍独立执行。`q` / `f` 作为快速 / 完整清单的旧快捷方式继续有效。

外置 JSON 由运行在被测机器上的客户端抓取，不在观测端下载。链接必须直接返回文件内容，不能是 GitHub 文件浏览页、登录页或网盘预览页；GitHub 可使用 Raw 链接。HTTPS 证书须可信，不读取环境代理；总超时 20 秒，最多跟随 5 次重定向，禁止降级到 HTTP。只把下载内容当作数据，不执行其中任何内容。

导入成功后，链接、校验后的域名和分类随选择保存在客户端配置中。下次回车沿用时不联网抓取；要刷新外置文件，重新输入 `4` 或 `1 4`，链接界面回车即可重新下载原链接。下载失败、整个 JSON 格式损坏或没有有效域名时，保留原配置，不悄悄改用别的清单。选择结果也适用于随后运行的 `sniroute client probe`；显式传入 `-sni` / `-sni-file` 时，仍以命令行域名为准。

## 外置文件规范

范本：[external-domains.v1.json](examples/external-domains.v1.json)。结构校验文件：[external-domains.schema.json](external-domains.schema.json)。范本使用 `.example` 演示域名，可替换成自己的清单。

```json
{
  "version": "v1",
  "name": "我的自定义清单",
  "domains": [
    {"domain": "chat.example", "category": "AI 服务"},
    {"domain": "code.example", "category": "开发工具"},
    {"domain": "assets.example"}
  ]
}
```

| 字段 | 规范 |
| --- | --- |
| `version` | 必填字符串，固定为 `"v1"`，表示外置文件格式 |
| `name` | 可选清单名称，最多 80 个字符，不含控制字符 |
| `domains` | 必填数组，1–10000 项；每项必须是对象 |
| `domain` | 必填字符串，只填域名，不能是 IP、URL、端口、路径或通配符 |
| `category` | 可选字符串，最多 64 个字符；省略、空字符串或纯空白时归入“其他” |

具体校验与合并规则：

- 文件使用 **UTF-8、合法 JSON**，最大 **2 MiB**；不接受注释、尾逗号或多个 JSON 文档。根对象和每个条目均不接受规范之外的字段。根对象结构错误会中止导入；条目结构错误只跳过对应条目。
- 域名前后空白会被去除、字母转为小写、末尾一个点会被去除。规范化后总长不超过 253 个 ASCII 字符，至少两个标签；每段 1–63 个字符，只允许字母、数字和连字符，首尾不能是连字符，最后一段必须含字母。国际化域名请先转成 Punycode；不自动修复输入，不通过 DNS 或真实网站访问验证域名是否存在。
- 格式错误的地址、IP 地址、`https://example.com`、`example.com:443`、`*.example.com`、`a_b.example`、空域名、数字或数组类型字段均会跳过。单个条目无效不会影响其他有效条目。`category: null` 也属于无效条目。
- 分类可自由命名，但最多 64 个不同分类，不能含换行、制表符等控制字符。缺少分类不跳过，直接归入 **“其他”**。
- 外置文件内同一域名仅保留第一条有效记录及其分类。与内置清单合并时同一域名只测一次；选用了外置清单时，该域名采用外置文件的分类，包括“其他”。未选外置清单时，不影响内置分类。
- 导入后显示有效域名数、跳过条目数和重复条目数，并最多展示前 5 条错误位置与原因。结构校验文件可用于编辑器提示；域名的完整语义规则以上述导入校验为准。
- 文件容量上限不等于任务规模上限：一个任务最多 4000 次尝试，基线、目标数量及轮数都占用额度。合并后超出额度时会提示缩小清单或减少轮数，不会静默截断域名。

## 用 AI 快速整理

可直接复制下面的提示词；[完整提示词文件](external-domains-ai-prompt.md)包含详细长度、字符及容量要求。

```text
请将我提供的材料整理为 SniRoute 外置域名清单，只输出合法 JSON，不要代码围栏、注释或解释。
根对象只用 version、name、domains；version 固定为 "v1"，name 为可选字符串。
domains 是对象数组，每项只用 domain 和 category，两个字段均为字符串。
只使用材料中出现的域名；如果材料是 URL，只提取 hostname。
域名转为小写并去重，不带协议、端口、路径、通配符；跳过 IP、1,2.3.4 等错误地址，不猜测修复。
域名至少两段，每段只含字母、数字或连字符，首尾不能是连字符；最后一段必须含字母。
保留材料已有分类，没有分类或无法确定时写“其他”，不要凭域名猜测归属或可达性。
重复域名保留第一条有效记录；category 最多 64 字符，最多 64 个分类。
输出为 UTF-8 JSON，最多 2 MiB、10000 项。没有有效域名时不要编造，返回空数组供我检查，空清单不可导入。
示例结构：{"version":"v1","name":"我的清单","domains":[{"domain":"chat.example","category":"AI 服务"}]}
原始材料：
（在此粘贴）
```
